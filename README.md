# SETask

Judul: SETask

Deskripsi: Projek Individu Software Engineering

Cara menjalankan project: 
- Download dan buka Git software
- Create repository baru
- Upload README dan file SC yang diinginkan melalui command prompt commit
- Buat dan tambahkan branch menggunakan git branch "Nama branch"
- Lakukan perubahan pada file SC di branch baru
- Lakukan merge menggunakan git merge [branch] untuk mengupdate file SC di main branch
